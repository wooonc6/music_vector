음악 취향 추천 시스템

사용자의 음악 취향을 벡터로 표현하고, 벡터 내적과 코사인 유사도를 이용해 가장 취향이 비슷한 사람을 찾는 모델입니다.

이 모델은 내 취향 벡터와 준희·재호·원준의 취향 벡터를 비교합니다.

1. 벡터 내적과 코사인 유사도

음악 취향을 7개의 장르 점수로 표현합니다.

K-pop, 힙합, 발라드, EDM, 인디, Rock, OST

a = (K-pop, 힙합, 발라드, EDM, 인디, Rock, OST)

내 취향 벡터를 a라고 하면, 우리는 a와 각 사용자의 벡터를 비교합니다.

a · 준희
a · 재호
a · 원준

내적은 같은 위치의 장르 점수끼리 곱한 뒤 모두 더하는 계산입니다.

a · b = a1×b1 + a2×b2 + ... + a7×b7

둘 다 같은 장르를 높게 좋아하면 큰 수끼리 곱해져 내적 값이 커집니다. 하지만 내적만 쓰면 점수를 전체적으로 높게 주는 사람이 유리할 수 있으므로, 벡터의 크기로 나누어 방향의 유사성을 비교합니다.

cos θ = (a · b) / (|a| |b|)

cos θ가 1에 가까울수록 두 취향 벡터의 방향이 비슷하다는 뜻입니다.

2. 내 음악 취향 입력하기

각 장르에 대해 0점부터 5점까지 선호도를 입력하세요.

3. 사전에 지정된 사용자 취향 벡터

사용자 K-pop 힙합 발라드 EDM 인디 Rock OST
준희 3245321
재호 5332123
원준 2132543

각 행은 한 사람의 7차원 취향 벡터입니다.

4. 가장 비슷한 사용자 찾기

내 취향 벡터 a와 준희, 재호, 원준의 벡터를 각각 비교해 cos θ 값이 가장 큰 사람을 찾습니다.
