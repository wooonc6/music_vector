17기 엠오와 함께하는 음악 취향 추천

❤️ 엠오 최초 참여형 자주발 ❤️

사용자 취향 벡터를 비교하여 가장 비슷한 음악 취향을 가진 사용자를 찾는 수학 모델링 프로그램

사용자의 음악 취향을 벡터로 표현하고, 벡터 내적과 코사인 유사도를 이용해 가장 취향이 비슷한 사람을 찾습니다!

1. 벡터 내적과 코사인 유사도

음악 취향을 7개의 장르 점수로 표현합니다.

K-pop, 힙합, 발라드, EDM, 인디, Rock, 재즈

사용자 취향 벡터 = (K-pop, 힙합, 발라드, EDM, 인디, Rock, 재즈)

입력된 사용자 취향 벡터를 a라고 하면, 프로그램은 a와 여러 사용자의 취향 벡터를 각각 비교합니다.

a · b = a1×b1 + a2×b2 + ... + a7×b7

내적은 같은 위치의 장르 점수끼리 곱한 뒤 모두 더하는 계산입니다. 둘 다 같은 장르를 높게 좋아하면 큰 수끼리 곱해져 내적 값이 커집니다. 하지만 내적만 쓰면 점수를 전체적으로 높게 주는 사람이 유리할 수 있으므로, 벡터의 크기로 나누어 방향의 유사성을 비교합니다.

cos θ = (a · b) / (|a| |b|)

cos θ가 1에 가까울수록 두 사용자 취향 벡터의 방향이 비슷하다는 뜻입니다.

2. 사용자 음악 취향 입력하기

각 장르에 대해 0점부터 5점까지 선호도를 입력하세요.

3. 비공개 고정 데이터 기반 비교

프로그램 내부에 저장된 17기 엠오 친구들의 음악 취향 벡터와 비교합니다. 실제 고정 데이터값은 화면에 표시하지 않고, 계산 결과에서 코사인 유사도만 확인할 수 있습니다.

4. 가장 비슷한 사용자 찾기

입력된 사용자 취향 벡터와 여러 사용자의 취향 벡터를 각각 비교해 cos θ 값이 가장 큰 사람을 찾습니다.

아직 계산 결과가 없습니다.
