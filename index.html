음악 취향 추천 시스템

이 웹페이지는 사용자의 음악 취향을 벡터로 표현하고, 벡터 내적과 코사인 유사도를 이용해 가장 취향이 비슷한 사람을 찾는 모델입니다.

비교하는 대상은 노래와 사용자가 아니라, 사용자와 사용자입니다.

1. 벡터 내적과 코사인 유사도

우리는 음악 취향을 다음 7개의 장르에 대한 선호도 점수로 나타냅니다.

K-pop, 힙합, 발라드, EDM, 인디, Rock, OST

예를 들어 어떤 사용자의 취향이 다음과 같다면,

a = (5, 3, 4, 2, 1, 2, 3)

이 사용자의 취향은 7차원 벡터 a로 표현됩니다.

무엇과 무엇을 비교하는가?

내 취향 벡터를 a라고 하고, 재호, 준희, 원준의 취향 벡터를 각각 b라고 두면 우리는 다음 값을 각각 계산합니다.

a · 준희, a · 재호, a · 원준

즉, 내 취향 벡터와 다른 사람의 취향 벡터를 하나씩 내적합니다.

내적의 의미

두 벡터의 내적은 같은 위치의 성분끼리 곱한 뒤 모두 더하는 계산입니다.

a · b = a1×b1 + a2×b2 + ... + a7×b7

예를 들어 두 사람이 K-pop을 모두 좋아하면 K-pop 점수끼리 곱한 값이 크게 더해집니다. 이렇게 같은 장르를 함께 좋아할수록 내적 값은 커집니다.

왜 코사인 유사도를 사용하는가?

내적 값만 사용하면 점수를 전반적으로 높게 주는 사람이 유리해질 수 있습니다. 그래서 벡터의 크기로 나누어 방향의 유사성을 비교합니다.

cos θ = (a · b) / (|a| |b|)

여기서 cos θ가 1에 가까울수록 두 취향 벡터의 방향이 비슷하다는 뜻입니다. 방향이 비슷하다는 것은 장르별 선호 패턴이 비슷하다는 의미입니다.

2. 내 음악 취향 입력하기

각 장르에 대해 0점부터 5점까지 선호도를 입력하세요.

3. 사전에 지정된 사용자 취향 벡터

발표용 모델에서는 세 명의 사용자 취향을 미리 정해두었습니다.

사용자 K-pop 힙합 발라드 EDM 인디 Rock OST
준희 3 2 4 5 3 2 1
재호 5 3 3 2 1 2 3
원준 2 1 3 2 5 4 3

각 행은 한 사람의 7차원 취향 벡터입니다.

4. 가장 비슷한 사용자 찾기

버튼을 누르면 내 취향 벡터와 준희, 재호, 원준의 벡터를 각각 비교합니다.

내 벡터 a vs 준희 벡터
내 벡터 a vs 재호 벡터
내 벡터 a vs 원준 벡터
아직 계산 결과가 없습니다.
