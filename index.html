음악 취향 추천 알고리즘 모델링

사용자의 음악 취향을 벡터로 표현하고, 벡터의 내적에서 유도되는 코사인 유사도를 이용해 가장 비슷한 취향의 사용자를 찾는 미니 추천 시스템입니다.

1. 수학적 원리

취향은 벡터가 될 수 있다

각 장르를 하나의 차원으로 두고, 선호도 점수를 좌표처럼 사용합니다.

a⃗ = (K-pop, 힙합, 발라드, EDM, 인디)

두 사용자의 취향이 비슷하다는 것은 두 벡터가 비슷한 방향을 향한다는 뜻으로 모델링할 수 있습니다.

cos θ = (a⃗ · b⃗) / (|a⃗||b⃗|)

코사인 유사도가 1에 가까울수록 두 사용자의 취향 패턴이 비슷합니다.
